#To-Do List (Command-Line)

This is a simple command-line To-Do List application written in Python. It allows you to:

- Add tasks
- View tasks
- Remove tasks
- Exit the program

It also handles edge cases like:
- Empty input
- Entering invalid task numbers
- Trying to remove a task from an empty list
